SUD Flasher

Flash the firmware straight from the browser. Use Chrome or Edge on a computer (needs Web Serial). Firmware build: __VER__

1. Display (CYD ESP32-2432S028)

  1. Connect the CYD to the computer with a USB cable.
  2. Click the button, choose the serial port, press Install.
Open this page in desktop Chrome or Edge. This page must be opened over HTTPS.

2. Camera (ESP32-CAM) via a USB-TTL adapter

The ESP32-CAM has no USB port, so use a USB-TTL adapter (CP2102 / CH340 / FT232).

U0RTX
U0TRX
IO0GND  (only while flashing)

TX goes to RX and RX goes to TX (crossed). If the adapter has a 3.3V/5V jumper, leave it on 3.3V logic where possible; the camera is powered from the 5V pin. If the board keeps rebooting, the adapter cannot supply enough current: power the CAM from a better 5V source (join the grounds) and add a 470-1000 uF capacitor between 5V and GND.

  1. Wire it as in the table, with the IO0 → GND wire in place.
  2. Plug the adapter into the computer and press the small RESET button on the CAM once (this enters flashing mode).
  3. Click the button, choose the adapter's port, tick Erase device the first time, press Install.
  4. When it says it is done: remove the IO0 → GND wire and press RESET again.
Open this page in desktop Chrome or Edge. This page must be opened over HTTPS.

The adapter has no auto-reset lines wired, so if the connection fails, press RESET on the CAM and try again (IO0 must still be tied to GND).

3. First setup after flashing

Camera: if it cannot connect, it opens its own network SUD-CAM (password cyddisplay). Join it with your phone, open http://192.168.4.1, and enter your Wi-Fi name, Wi-Fi password and the Gemini API key. Save, and it restarts.

Display: on the first start it asks you to tap three crosses (touch calibration). In the calculator type 1337 and press =, enter the PIN 2580, open WEB, press AP ON. Join the network SUD (password cyddisplay), open http://sud.local (or 192.168.4.1), log in as admin / cyddisplay and use Settings to set the Wi-Fi name and password (the same network as the camera), a new PIN, secret combo and password.

The firmware contains no passwords or keys, everything is stored on the device. The "Erase device" option clears the settings.
